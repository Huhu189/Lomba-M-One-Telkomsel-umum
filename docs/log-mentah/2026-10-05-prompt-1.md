## 2026-10-05 — Perbaikan saat menyiapkan pagar mutu

Catatan jujur beberapa jebakan yang ditemui dan cara mengatasinya:

- Pest v5 butuh `pest()->extend(Tests\TestCase::class)->in('Feature')` di `tests/Pest.php`
  (sebelumnya ditulis di subfolder, tidak terbaca).
- Arch test harus di berkas ber-suffix `Test.php`; dipindah ke `tests/Arch/ArchitectureTest.php`
  dan suite "Arch" didaftarkan di `phpunit.xml`.
- `routes/api.php` awalnya tidak terdaftar di `bootstrap/app.php` sehingga health endpoint 404;
  diperbaiki dengan menambahkan `api:` pada `withRouting` + `statefulApi()` untuk Sanctum SPA.
- Pint gagal pada file scaffold tanpa strict_types; diberi `pint.json` berisi
  `declare_strict_types` sehingga seluruh file PHP otomatis diberi `declare(strict_types=1)`.
- TypeScript 6 menghapus opsi `baseUrl` pada jsconfig; diganti `paths` relatif `./src/*`.
- `@eslint/js` terbaru menuntut ESLint 10; dipin ke ESLint 9 + `@eslint/js@9`.
- npm 404 saat install karena salah nama paket `@tanstack/query` (yang benar `@tanstack/react-query`).
