# Bukti Konfirmasi Panitia

Folder ini menyimpan bukti konfirmasi tertulis dari panitia lomba
(screenshot, email, atau catatan percakapan) untuk hal-hal seperti:

- konfirmasi keterlambatan pengumpulan (bila terjadi, sanksi -10%);
- konfirmasi konflik antara prompt dan spesifikasi resmi lomba;
- konfirmasi aturan yang tidak jelas.

Belum ada konfirmasi yang perlu disimpan per 5 Oktober 2026.

Format penamaan yang disarankan: `YYYY-MM-DD-topik.md` atau lampiran gambar
dengan nama serupa, sehingga mudah diekspor ke `docs/word/` bila diperlukan.
