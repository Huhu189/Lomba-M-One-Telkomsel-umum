# Bukti Konfirmasi Panitia

Folder ini menyimpan bukti konfirmasi tertulis dari panitia lomba
(screenshot, email, atau catatan percakapan) untuk tanggapan hal-hal seperti:

- konfirmasi keterlambatan pengumpulan
- konfirmasi konflik antara prompt dan spesifikasi resmi lomba;
- konfirmasi aturan yang tidak jelas.
